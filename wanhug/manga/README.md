# わん酵素 腎臓サポート｜漫画LP

15ページの漫画形式の商品紹介ページです。画像・吹き出し・テキスト・動画を分けて構成しています。

## 開き方

`index.html` が1ページ目です。`page-1.html`〜`page-15.html` から各ページを直接開くこともできます。HTMLと `assets/` を同じ階層のまま静的ホスティングに配置してください。

## 操作

- スマートフォンで左にスワイプすると次のページ、右にスワイプすると前のページへ進みます。
- ページ下部の移動ボタンでも進めます。
- 7ページ目の発酵の説明はタップで切り替えます。
- 13ページ目の動画はタップで再生・停止できます。
- 15ページ目の商品詳細ボタンは、指定の商品ページを新しいタブで開きます。

## ファイル

- `index.html`：漫画の入口（1ページ目と同じ内容）
- `page-N.html`：各ページの画面、文字、アニメーション
- `assets/manga-swipe.js`：左右スワイプの判定
- `assets/`：各ページで使用する画像と動画
